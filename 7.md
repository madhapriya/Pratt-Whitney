# 1. Product of Array Except Self

**Difficulty:** Medium  
**Pattern:** Array / Prefix and Suffix Products

## Problem Statement

Given an integer array `nums`, return an array `answer` such that `answer[i]` is equal to the product of all the elements of `nums` except `nums[i]`.

Do not use division. The solution should run in `O(n)` time.

## Input Format

```text
nums = [1,2,3,4]
```

## Output Format

```text
[24,12,8,6]
```

## Constraints

- `2 <= nums.length <= 10^5`
- `-30 <= nums[i] <= 30`
- The product of any prefix or suffix fits in a 32-bit integer.
- Division is not allowed.

## Example

```text
Input:  [1,2,3,4]
Output: [24,12,8,6]

Additional Example 2 Input:  [-1,1,0,-3,3]
Additional Example 2 Output: [0,0,9,0,0]

Additional Example 3 Input:  [2,3,4,5]
Additional Example 3 Output: [60,40,30,24]
```

## Approach

Use prefix and suffix products.

- `left[i]` stores the product of all elements before index `i`.
- `right[i]` stores the product of all elements after index `i`.
- The final answer is `left[i] * right[i]`.

Initialize `left[0] = 1` because there are no elements before the first position. Initialize `right[n - 1] = 1` because there are no elements after the last position.

The screenshot solution uses separate `left`, `right`, and `output` arrays. This is easy to understand. A more space-efficient version can store prefix products directly in the output array and maintain one suffix-product variable.

## Iteration / Dry Run

For `nums = [1,2,3,4]`, let `n = 4`.

### Step 1: Initialize the arrays

```text
left   = [0,0,0,0]
right  = [0,0,0,0]
output = [0,0,0,0]

left[0] = 1
right[3] = 1
```

`left[0] = 1` because there are no elements to the left of index 0.  
`right[3] = 1` because there are no elements to the right of index 3.

### Step 2: Build the left product array

The loop runs from `i = 1` to `i = 3`.

| Iteration | `i` | Calculation | Updated `left` |
|---:|---:|---|---|
| 1 | 1 | `left[1] = left[0] * nums[0] = 1 * 1 = 1` | `[1,1,0,0]` |
| 2 | 2 | `left[2] = left[1] * nums[1] = 1 * 2 = 2` | `[1,1,2,0]` |
| 3 | 3 | `left[3] = left[2] * nums[2] = 2 * 3 = 6` | `[1,1,2,6]` |

Final `left = [1,1,2,6]`.

### Step 3: Build the right product array

The loop runs backwards from `i = 2` to `i = 0`.

| Iteration | `i` | Calculation | Updated `right` |
|---:|---:|---|---|
| 1 | 2 | `right[2] = right[3] * nums[3] = 1 * 4 = 4` | `[0,0,4,1]` |
| 2 | 1 | `right[1] = right[2] * nums[2] = 4 * 3 = 12` | `[0,12,4,1]` |
| 3 | 0 | `right[0] = right[1] * nums[1] = 12 * 2 = 24` | `[24,12,4,1]` |

Final `right = [24,12,4,1]`.

### Step 4: Build the output array

For every index, multiply the left product and right product.

| Iteration | Index | Calculation | `output` |
|---:|---:|---|---|
| 1 | 0 | `1 * 24 = 24` | `[24,0,0,0]` |
| 2 | 1 | `1 * 12 = 12` | `[24,12,0,0]` |
| 3 | 2 | `2 * 4 = 8` | `[24,12,8,0]` |
| 4 | 3 | `6 * 1 = 6` | `[24,12,8,6]` |

**Answer = `[24,12,8,6]`**

Each output position is the product of every array element except the element at that position. No division is used.

## Java Solution

```java
class Solution {
    public int[] productExceptSelf(int[] nums) {
        int n = nums.length;

        int[] left = new int[n];
        int[] right = new int[n];
        int[] output = new int[n];

        left[0] = 1;
        right[n - 1] = 1;

        for (int i = 1; i < n; i++) {
            left[i] = left[i - 1] * nums[i - 1];
        }

        for (int i = n - 2; i >= 0; i--) {
            right[i] = right[i + 1] * nums[i + 1];
        }

        for (int i = 0; i < n; i++) {
            output[i] = left[i] * right[i];
        }

        return output;
    }
}
```

## Python Solution

```python
class Solution:
    def productExceptSelf(self, nums):
        n = len(nums)

        left = [1] * n
        right = [1] * n
        output = [1] * n

        for i in range(1, n):
            left[i] = left[i - 1] * nums[i - 1]

        for i in range(n - 2, -1, -1):
            right[i] = right[i + 1] * nums[i + 1]

        for i in range(n):
            output[i] = left[i] * right[i]

        return output
```

**Time:** `O(n)`  
**Space:** `O(n)` for the separate left and right arrays.

# 2. Rotate Array

**Difficulty:** Medium  
**Pattern:** Array / In-place Reversal / Two Pointers

## Problem Statement

Given an integer array `nums`, rotate the array to the right by `k` steps, where `k` is non-negative.

A right rotation moves each element `k` positions to the right. Elements that move beyond the end of the array wrap around to the beginning.

## Input Format

```text
nums = [1,2,3,4,5,6,7]
k = 3
```

## Output Format

```text
[5,6,7,1,2,3,4]
```

## Constraints

- `1 <= nums.length <= 10^5`
- `-2^31 <= nums[i] <= 2^31 - 1`
- `0 <= k <= 10^5`

## Example

```text
Input:  nums = [1,2,3,4,5,6,7], k = 3
Output: [5,6,7,1,2,3,4]

Additional Example 2 Input:  nums = [-1,-100,3,99], k = 2
Additional Example 2 Output: [3,99,-1,-100]

Additional Example 3 Input:  nums = [1,2], k = 3
Additional Example 3 Output: [2,1]
```

## Approach

Use the three-reversal method shown in the screenshot.

First calculate `k = k % n`, because rotating an array by its length returns the same array.

Then:

1. Reverse the entire array.
2. Reverse the first `k` elements.
3. Reverse the remaining `n-k` elements.

The `reverse()` helper swaps values from the two ends and moves its pointers inward. This approach modifies the original array without creating another array.

## Iteration / Dry Run

For `nums = [1,2,3,4,5,6,7]`, `k = 3`.

### Step 1: Normalize k

```text
n = 7
k = k % n
k = 3 % 7 = 3
```

We need to rotate the array right by 3 positions.

### Step 2: Reverse the entire array

Call `reverse(nums, 0, 6)`.

| Swap | `start` | `end` | Values swapped | Array after swap |
|---:|---:|---:|---|---|
| 1 | 0 | 6 | 1 and 7 | `[7,2,3,4,5,6,1]` |
| 2 | 1 | 5 | 2 and 6 | `[7,6,3,4,5,2,1]` |
| 3 | 2 | 4 | 3 and 5 | `[7,6,5,4,3,2,1]` |

The pointers meet at index 3, so this reversal stops.

### Step 3: Reverse the first k elements

Call `reverse(nums, 0, 2)`.

| Swap | `start` | `end` | Values swapped | Array after swap |
|---:|---:|---:|---|---|
| 1 | 0 | 2 | 7 and 5 | `[5,6,7,4,3,2,1]` |

Now the first three elements are `[5,6,7]`.

### Step 4: Reverse the remaining elements

Call `reverse(nums, 3, 6)`.

| Swap | `start` | `end` | Values swapped | Array after swap |
|---:|---:|---:|---|---|
| 1 | 3 | 6 | 4 and 1 | `[5,6,7,1,3,2,4]` |
| 2 | 4 | 5 | 3 and 2 | `[5,6,7,1,2,3,4]` |

The array is now rotated to the right by 3 positions.

**Answer = `[5,6,7,1,2,3,4]`**

The order of the three reversals is important: reverse all, reverse the first k, then reverse the remaining n-k elements.

## Java Solution

```java
class Solution {
    public void rotate(int[] nums, int k) {
        int n = nums.length;
        k = k % n;

        reverse(nums, 0, n - 1);
        reverse(nums, 0, k - 1);
        reverse(nums, k, n - 1);
    }

    private void reverse(int[] nums, int start, int end) {
        while (start < end) {
            int temp = nums[start];
            nums[start] = nums[end];
            nums[end] = temp;

            start++;
            end--;
        }
    }
}
```

## Python Solution

```python
class Solution:
    def rotate(self, nums, k):
        n = len(nums)
        k = k % n

        def reverse(start, end):
            while start < end:
                nums[start], nums[end] = nums[end], nums[start]
                start += 1
                end -= 1

        reverse(0, n - 1)
        reverse(0, k - 1)
        reverse(k, n - 1)
```

**Time:** `O(n)`  
**Space:** `O(1)` auxiliary space.

# 3. Max Consecutive Ones

**Difficulty:** Easy  
**Pattern:** Array / Counting / Sliding Window

## Problem Statement

Given a binary array `nums`, return the maximum number of consecutive `1`s in the array.

A sequence is consecutive when all its values are `1` and there is no `0` between them.

## Input Format

```text
nums = [1,1,0,1,1,1]
```

## Output Format

```text
3
```

## Constraints

- `1 <= nums.length <= 10^5`
- `nums[i]` is either `0` or `1`.

## Example

```text
Input:  [1,1,0,1,1,1]
Output: 3

Additional Example 2 Input:  [1,0,1,1,0,1]
Additional Example 2 Output: 2

Additional Example 3 Input:  [1,1,1,1]
Additional Example 3 Output: 4
```

## Approach

Maintain two variables:

- `count` = current consecutive count of ones.
- `ans` = maximum consecutive count found so far.

Traverse the array:

- If the current value is `1`, increment `count`.
- If the current value is `0`, reset `count` to `0`.
- Update `ans` whenever `count` becomes larger.

This is a single-pass solution and does not need an extra array.

## Iteration / Dry Run

For `nums = [1,1,0,1,1,1]`.

Initialize:

```text
count = 0
ans = 0
```

### Step-by-step iteration

| Iteration | Index | `nums[i]` | What happens | `count` after iteration | `ans` after iteration |
|---:|---:|---:|---|---:|---:|
| 1 | 0 | 1 | One found, increment count | 1 | 1 |
| 2 | 1 | 1 | One found, increment count | 2 | 2 |
| 3 | 2 | 0 | Zero found, reset count to 0 | 0 | 2 |
| 4 | 3 | 1 | One found, increment count | 1 | 2 |
| 5 | 4 | 1 | One found, increment count | 2 | 2 |
| 6 | 5 | 1 | One found, increment count | 3 | 3 |

### Understand the reset

- The first two `1`s form a consecutive group of length 2.
- At index 2, the value is `0`, so the current group ends and `count` becomes 0.
- The final three `1`s form a new group of length 3.
- `ans` stores the largest group length seen, so it remains 3.

**Answer = 3**

## Java Solution

```java
class Solution {
    public int findMaxConsecutiveOnes(int[] nums) {
        int ans = 0;
        int count = 0;

        for (int i = 0; i < nums.length; i++) {
            if (nums[i] == 0) {
                count = 0;
            } else {
                count++;
            }

            if (count > ans) {
                ans = count;
            }
        }

        return ans;
    }
}
```

## Python Solution

```python
class Solution:
    def findMaxConsecutiveOnes(self, nums):
        ans = 0
        count = 0

        for num in nums:
            if num == 0:
                count = 0
            else:
                count += 1

            ans = max(ans, count)

        return ans
```

**Time:** `O(n)`  
**Space:** `O(1)`

# 4. Maximum Subarray

**Difficulty:** Medium  
**Pattern:** Array / Kadane's Algorithm / Dynamic Programming

## Problem Statement

Given an integer array `nums`, find the contiguous subarray with the largest sum and return that sum.

The subarray must contain at least one element.

## Input Format

```text
nums = [-2,1,-3,4,-1,2,1,-5,4]
```

## Output Format

```text
6
```

## Constraints

- `1 <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`

## Example

```text
Input:  [-2,1,-3,4,-1,2,1,-5,4]
Output: 6

Additional Example 2 Input:  [1]
Additional Example 2 Output: 1

Additional Example 3 Input:  [5,4,-1,7,8]
Additional Example 3 Output: 23
```

## Approach

Use Kadane's algorithm.

Maintain:

- `currentSum` = maximum sum of a subarray ending at the current index.
- `maxSoFar` = maximum subarray sum found so far.

At each new value:

1. If `currentSum` is negative, reset it to `0`.
2. Add the current element.
3. Update `maxSoFar` if the new `currentSum` is larger.

The initial value of `maxSoFar` is `nums[0]`, so arrays containing only negative values are handled correctly.

## Iteration / Dry Run

For `nums = [-2,1,-3,4,-1,2,1,-5,4]`.

Initialize using the first element:

```text
maxSoFar = -2
currentSum = -2
```

For each next element, first reset `currentSum` to 0 if it is negative. Then add the current number and update `maxSoFar`.

### Step-by-step iteration

| Iteration | Index | Number | `currentSum` before processing | Reset needed? | `currentSum` after adding | `maxSoFar` |
|---:|---:|---:|---:|---|---:|---:|
| Initial | 0 | -2 | — | Initial value | -2 | -2 |
| 1 | 1 | 1 | -2 | Yes, reset to 0 | 1 | 1 |
| 2 | 2 | -3 | 1 | No | -2 | 1 |
| 3 | 3 | 4 | -2 | Yes, reset to 0 | 4 | 4 |
| 4 | 4 | -1 | 4 | No | 3 | 4 |
| 5 | 5 | 2 | 3 | No | 5 | 5 |
| 6 | 6 | 1 | 5 | No | 6 | 6 |
| 7 | 7 | -5 | 6 | No | 1 | 6 |
| 8 | 8 | 4 | 1 | No | 5 | 6 |

### Identify the best subarray

At index 3, the running sum starts at 4. It continues through `-1`, `2`, and `1`:

```text
4 + (-1) + 2 + 1 = 6
```

The best subarray is `[4,-1,2,1]`.

**Answer = 6**

Important: `maxSoFar` starts at `nums[0]`, not 0. This ensures an all-negative input such as `[-5,-2,-8]` returns `-2`, not 0.

## Java Solution

```java
class Solution {
    public int maxSubArray(int[] nums) {
        int maxSoFar = nums[0];
        int currentSum = nums[0];

        for (int i = 1; i < nums.length; i++) {
            if (currentSum < 0) {
                currentSum = 0;
            }

            currentSum = currentSum + nums[i];

            if (currentSum > maxSoFar) {
                maxSoFar = currentSum;
            }
        }

        return maxSoFar;
    }
}
```

## Python Solution

```python
class Solution:
    def maxSubArray(self, nums):
        max_so_far = nums[0]
        current_sum = nums[0]

        for num in nums[1:]:
            if current_sum < 0:
                current_sum = 0

            current_sum += num
            max_so_far = max(max_so_far, current_sum)

        return max_so_far
```

**Time:** `O(n)`  
**Space:** `O(1)`

# 5. Best Time to Buy and Sell Stock

**Difficulty:** Easy  
**Pattern:** Array / Greedy

## Problem Statement

You are given an array `prices`, where `prices[i]` is the stock price on day `i`.

Choose one day to buy one stock and a later day to sell it so that the profit is maximum.

Return the maximum profit. If no profit is possible, return `0`.

## Input Format

```text
prices = [7,1,5,3,6,4]
```

## Output Format

```text
5
```

## Constraints

- `1 <= prices.length <= 10^5`
- `0 <= prices[i] <= 10^4`

## Example

```text
Input:  [7,1,5,3,6,4]
Output: 5

Additional Example 2 Input:  [7,6,4,3,1]
Additional Example 2 Output: 0

Additional Example 3 Input:  [2,4,1]
Additional Example 3 Output: 2
```

## Approach

Maintain two variables:

- `minSoFar` = minimum stock price seen before or on the current day.
- `ans` = maximum profit found so far.

For every day:

1. Calculate `profit = prices[i] - minSoFar`.
2. Update `ans` if this profit is greater.
3. Update `minSoFar` with the current price.

The minimum price is updated after calculating the profit, ensuring the buy day is not later than the sell day.

## Iteration / Dry Run

For `prices = [7,1,5,3,6,4]`.

Initialize:

```text
minSoFar = prices[0] = 7
ans = 0
```

For every later day, calculate the profit using the lowest price seen so far. Then update the minimum price.

### Step-by-step iteration

| Iteration | Day/index | Current price | `minSoFar` before update | Profit = price - minSoFar | `ans` after profit check | `minSoFar` after update |
|---:|---:|---:|---:|---:|---:|---:|
| Initial | 0 | 7 | — | — | 0 | 7 |
| 1 | 1 | 1 | 7 | 1 - 7 = -6 | 0 | 1 |
| 2 | 2 | 5 | 1 | 5 - 1 = 4 | 4 | 1 |
| 3 | 3 | 3 | 1 | 3 - 1 = 2 | 4 | 1 |
| 4 | 4 | 6 | 1 | 6 - 1 = 5 | 5 | 1 |
| 5 | 5 | 4 | 1 | 4 - 1 = 3 | 5 | 1 |

### Understand the best transaction

- The lowest buying price encountered is `1` on day 1.
- Selling at price `6` on day 4 gives profit `6 - 1 = 5`.
- No later day gives a larger profit.

**Answer = 5**

The code calculates profit before updating `minSoFar`, so the stock is always bought on an earlier day or the same day is never used to create a positive profit.

## Java Solution

```java
class Solution {
    public int maxProfit(int[] prices) {
        int minSoFar = prices[0];
        int ans = 0;

        for (int i = 1; i < prices.length; i++) {
            int profit = prices[i] - minSoFar;

            if (profit > ans) {
                ans = profit;
            }

            minSoFar = Math.min(prices[i], minSoFar);
        }

        return ans;
    }
}
```

## Python Solution

```python
class Solution:
    def maxProfit(self, prices):
        min_so_far = prices[0]
        ans = 0

        for price in prices[1:]:
            profit = price - min_so_far
            ans = max(ans, profit)
            min_so_far = min(min_so_far, price)

        return ans
```

**Time:** `O(n)`  
**Space:** `O(1)`

# 6. Maximum Product Subarray

**Difficulty:** Medium  
**Pattern:** Array / Dynamic Programming / Tracking Maximum and Minimum

## Problem Statement

Given an integer array `nums`, find a contiguous non-empty subarray that has the largest product, and return the product.

## Input Format

```text
nums = [2,3,-2,4]
```

## Output Format

```text
6
```

## Constraints

- `1 <= nums.length <= 2 * 10^4`
- `-10 <= nums[i] <= 10`
- The product of any subarray fits in a 32-bit integer.

## Example

```text
Input:  [2,3,-2,4]
Output: 6

Additional Example 2 Input:  [-2,0,-1]
Additional Example 2 Output: 0

Additional Example 3 Input:  [-2,3,-4]
Additional Example 3 Output: 24
```

## Approach

Maintain three values:

- `maxProduct` = maximum product of a subarray ending at the current index.
- `minProduct` = minimum product of a subarray ending at the current index.
- `result` = maximum product found so far.

Both maximum and minimum products are needed because multiplying by a negative number can turn a large negative product into a large positive product.

For every current number:

1. If it is negative, swap the roles of the previous maximum and minimum.
2. Update the maximum product.
3. Update the minimum product.
4. Update the final result.

The screenshot uses this maximum/minimum tracking idea. The implementation below uses the same logic in a shorter form.

## Iteration / Dry Run

For `nums = [2,3,-2,4]`.

Initialize:

```text
maxProduct = 2
minProduct = 2
result = 2
```

We track both maximum and minimum products because multiplying by a negative number changes the sign. A previous minimum can become the new maximum after multiplication by a negative number.

### Step-by-step iteration

| Iteration | Current value | Previous max | Previous min | Negative? | New max | New min | Result |
|---:|---:|---:|---:|---|---:|---:|---:|
| Initial | 2 | — | — | — | 2 | 2 | 2 |
| 1 | 3 | 2 | 2 | No | `max(3, 2*3) = 6` | `min(3, 2*3) = 3` | 6 |
| 2 | -2 | 6 | 3 | Yes: swap | `max(-2, 3*-2) = -2` | `min(-2, 6*-2) = -12` | 6 |
| 3 | 4 | -2 | -12 | No | `max(4, -2*4) = 4` | `min(4, -12*4) = -48` | 6 |

### Why do we swap for a negative number?

Before processing `-2`:

```text
maxProduct = 6
minProduct = 3
```

After swapping:

```text
maxProduct = 3
minProduct = 6
```

Then multiply both by `-2`:

```text
3 * -2 = -6
6 * -2 = -12
```

The current value `-2` itself is larger than `-6`, so the new maximum is `-2`; the new minimum is `-12`.

**Answer = 6**, from subarray `[2,3]`.

A negative number can reverse which previous product is useful, which is why both maximum and minimum values must be tracked.

## Java Solution

```java
class Solution {
    public int maxProduct(int[] nums) {
        int maxProduct = nums[0];
        int minProduct = nums[0];
        int result = nums[0];

        for (int i = 1; i < nums.length; i++) {
            int current = nums[i];

            if (current < 0) {
                int temp = maxProduct;
                maxProduct = minProduct;
                minProduct = temp;
            }

            maxProduct = Math.max(current, maxProduct * current);
            minProduct = Math.min(current, minProduct * current);

            result = Math.max(result, maxProduct);
        }

        return result;
    }
}
```

## Python Solution

```python
class Solution:
    def maxProduct(self, nums):
        max_product = nums[0]
        min_product = nums[0]
        result = nums[0]

        for current in nums[1:]:
            if current < 0:
                max_product, min_product = min_product, max_product

            max_product = max(current, max_product * current)
            min_product = min(current, min_product * current)

            result = max(result, max_product)

        return result
```

**Time:** `O(n)`  
**Space:** `O(1)`

# 7. Valid Sudoku

**Difficulty:** Medium  
**Pattern:** Matrix / Hashing / Row, Column and Sub-box Validation

## Problem Statement

Determine if a `9 x 9` Sudoku board is valid.

Only the filled cells need to be validated according to these rules:

1. Each row must contain the digits `1` to `9` without repetition.
2. Each column must contain the digits `1` to `9` without repetition.
3. Each of the nine `3 x 3` sub-boxes must contain the digits `1` to `9` without repetition.

A cell containing `'.'` is empty and should be ignored.

A Sudoku board may be valid even if it is not yet complete.

## Input Format

```text
board = [
  ["5","3",".",".","7",".",".",".","."],
  ["6",".",".","1","9","5",".",".","."],
  [".","9","8",".",".",".",".","6","."],
  ["8",".",".",".","6",".",".",".","3"],
  ["4",".",".","8",".","3",".",".","1"],
  ["7",".",".",".","2",".",".",".","6"],
  [".","6",".",".",".",".","2","8","."],
  [".",".",".","4","1","9",".",".","5"],
  [".",".",".",".","8",".",".","7","9"]
]
```

## Output Format

```text
true
```

## Constraints

- `board.length == 9`
- `board[i].length == 9`
- `board[i][j]` is a digit `1` to `9` or `'.'`.

## Example

```text
Input:  A partially filled board with no repeated digit in any row, column, or 3 x 3 box.
Output: true

Additional Example 2 Input:  A board with two 5s in the same row.
Additional Example 2 Output: false

Additional Example 3 Input:  A board with two 7s in the same 3 x 3 box.
Additional Example 3 Output: false
```

## Approach

Use three sets for every row, column, and 3 x 3 box.

- `rowSet[i]` stores digits already seen in row `i`.
- `colSet[j]` stores digits already seen in column `j`.
- `gridSet[gridNo]` stores digits already seen in the corresponding 3 x 3 box.

For every cell `(i, j)`:

1. Ignore the cell if it contains `'.'`.
2. Calculate its 3 x 3 box number using:

```text
gridNo = (i / 3) * 3 + (j / 3)
```

3. If the digit already exists in the row, column, or box set, return `false`.
4. Otherwise, add the digit to all three sets.

The box formula maps the 9 boxes to indexes `0` through `8`.

|---:|---|---|---:|

## Iteration / Dry Run

Use the example board from the problem statement. Rows and columns are indexed from `0` to `8`. A dot `'.'` is an empty cell and is skipped.

The algorithm scans the board row by row, from left to right. For each filled cell, it checks the row set, column set, and 3 x 3 box set.

### Step 1: Understand the box number formula

```text
gridNo = (i / 3) * 3 + (j / 3)
```

In Java, integer division is used.

For example, for row `i = 4` and column `j = 7`:

```text
gridNo = (4 / 3) * 3 + (7 / 3)
       = 1 * 3 + 2
       = 5
```

This cell belongs to box 5, the middle-right 3 x 3 box.

### Step 2: Trace the first row

The first row is:

```text
['5','3','.','.','7','.','.','.','.']
```

| Cell `(i,j)` | Value | Box number | Checks | Action |
|---|---:|---:|---|---|
| (0,0) | 5 | 0 | Not in row 0, column 0, or box 0 | Add 5 to all three sets |
| (0,1) | 3 | 0 | Not in row 0, column 1, or box 0 | Add 3 to all three sets |
| (0,2) | . | — | Empty cell | Skip |
| (0,3) | . | — | Empty cell | Skip |
| (0,4) | 7 | 1 | Not in row 0, column 4, or box 1 | Add 7 to all three sets |
| (0,5) to (0,8) | . | — | Empty cells | Skip |

After row 0, the row set contains `{5,3,7}`.

### Step 3: Trace more filled cells

| Cell `(i,j)` | Value | Box calculation | Box number | Result |
|---|---:|---|---:|---|
| (1,0) | 6 | `(1/3)*3 + (0/3)` | 0 | Valid; add 6 |
| (1,3) | 1 | `(1/3)*3 + (3/3)` | 1 | Valid; add 1 |
| (1,4) | 9 | `(1/3)*3 + (4/3)` | 1 | Valid; add 9 |
| (1,5) | 5 | `(1/3)*3 + (5/3)` | 1 | Valid; add 5 |
| (2,1) | 9 | `(2/3)*3 + (1/3)` | 0 | Valid; add 9 |
| (2,2) | 8 | `(2/3)*3 + (2/3)` | 0 | Valid; add 8 |
| (2,7) | 6 | `(2/3)*3 + (7/3)` | 2 | Valid; add 6 |
| (3,0) | 8 | `(3/3)*3 + (0/3)` | 3 | Valid; add 8 |
| (3,4) | 6 | `(3/3)*3 + (4/3)` | 4 | Valid; add 6 |
| (3,8) | 3 | `(3/3)*3 + (8/3)` | 5 | Valid; add 3 |
| (4,0) | 4 | `(4/3)*3 + (0/3)` | 3 | Valid; add 4 |
| (4,3) | 8 | `(4/3)*3 + (3/3)` | 4 | Valid; add 8 |
| (4,5) | 3 | `(4/3)*3 + (5/3)` | 4 | Valid; add 3 |
| (4,8) | 1 | `(4/3)*3 + (8/3)` | 5 | Valid; add 1 |

The same checks continue for every remaining filled cell in rows 5 through 8. No filled digit is repeated in its row, column, or 3 x 3 box.

### Step 4: Understand when the algorithm returns false

Suppose a second `'5'` appears in row 0. Then:

```text
rowSet[0].contains('5') == true
```

The condition is true, so the method immediately returns `false`.

A duplicate in a column or a 3 x 3 box is detected in the same way.

### Final result

The supplied example board contains no duplicate in any row, column, or 3 x 3 box.

**Answer = `true`**

## Java Solution

```java
import java.util.HashSet;
import java.util.Set;

class Solution {
    public boolean isValidSudoku(char[][] board) {
        Set<Character>[] rowSet = new HashSet[9];
        Set<Character>[] colSet = new HashSet[9];
        Set<Character>[] gridSet = new HashSet[9];

        for (int i = 0; i < 9; i++) {
            rowSet[i] = new HashSet<>();
            colSet[i] = new HashSet<>();
            gridSet[i] = new HashSet<>();
        }

        for (int i = 0; i < 9; i++) {
            for (int j = 0; j < 9; j++) {
                char value = board[i][j];

                if (value == '.') {
                    continue;
                }

                int gridNo = (i / 3) * 3 + (j / 3);

                if (rowSet[i].contains(value) ||
                    colSet[j].contains(value) ||
                    gridSet[gridNo].contains(value)) {
                    return false;
                }

                rowSet[i].add(value);
                colSet[j].add(value);
                gridSet[gridNo].add(value);
            }
        }

        return true;
    }
}
```

## Python Solution

```python
class Solution:
    def isValidSudoku(self, board):
        rows = [set() for _ in range(9)]
        cols = [set() for _ in range(9)]
        boxes = [set() for _ in range(9)]

        for i in range(9):
            for j in range(9):
                value = board[i][j]

                if value == ".":
                    continue

                box_no = (i // 3) * 3 + (j // 3)

                if (value in rows[i] or
                    value in cols[j] or
                    value in boxes[box_no]):
                    return False

                rows[i].add(value)
                cols[j].add(value)
                boxes[box_no].add(value)

        return True
```

**Time:** `O(1)` for a fixed `9 x 9` board (more generally `O(n²)` for an `n x n` board).  
**Space:** `O(1)` for a fixed `9 x 9` board (more generally `O(n²)`).
