# DSA Interview Problems – GitHub Folder

Each topic is a separate Markdown file. Each problem follows this exact structure:

Problem Statement → Input Format → Output Format → Constraints → Example → Approach → Iteration / Dry Run → Java Solution → Python Solution → Time / Space.

Every problem includes the original example and two additional input/output examples. One recommended implementation is included in each language to keep the format consistent with the supplied sample.
